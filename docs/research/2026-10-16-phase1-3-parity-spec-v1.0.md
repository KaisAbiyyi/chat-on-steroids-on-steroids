## Frozen contracts

| Contract | Evidence | Required invariant |
| --- | --- | --- |
| Config/defaults/recovery/migrations | `fixtures/upstream/config-*.json`, baseline manifest | Preserve platform defaults, unknown-field stripping, strict objects, catch/default behavior, legacy migrations, reserved root repair; corrupt files retain raw backup and conservative permissions. |
| Config validation interpreter | Generated Zod contract, pinned SHA in `config.rs` | Rust executes recognized validation rules. Regeneration requires a reviewed port; no JavaScript engine is shipped. |
| Durable state | Foundation tests and original `durable.test.ts` | Frozen generation, one serialized commit per file, exact immediate write, coalesced background work/retry, strict authority reads, publication after successful commit. |
| Protected Windows secrets | Isolated Electron/Rust two-way probe | Chromium v10 AES-256-GCM; DPAPI-protected master key in `Local State`; preserve unknown string keys; unavailable/decrypt-failed state cannot be overwritten by an empty view. |
| Session journal and canonical shards | Actual `store.ts` operations in `history-case.json` | Preserve JSONL append sequence, stable logical key and SHA-256 shard name, lazy messages.json overlay, immutable first position, terminal final body and latest authored revision. |
| Frontend replacement | `rebind-case.json`, Rust epoch/collision tests | Same local session ID, lifetime totals retained, current context reset, retired chat retained, stale source and competing owner refused. |
| Request identity | Original correlation tests plus Rust authority tests | First proven conversation **and local session epoch** win. Tool names, timing, tabs and agent payloads are never proof. Commit precedes acknowledgement. |
| Trust/Block | Original ledgers plus Rust policy tests | Block takes precedence, strict mode needs attribution, worker trust derives from a currently proven prime, committed resume ancestry derives trust without copying it. Failed grant cannot retry into authority later. |
| Chronology and export | Actual pure functions and history fixtures | Sequence stays the cursor domain. Turn-local presentation order, final-message residence and Markdown transcript selection remain separate. Full audit JSON retains tool/turn records. |
| Text, assets and retention | Original source limits and Rust tests | 256k UTF-16 user text, 12k assistant, 8k tool inline previews; overflow original stored when within 8 MiB asset limits. Content-addressed assets, 192 MiB session and configurable global quotas. No automatic age-based deletion. |
| Search | Actual accent/case fixtures, overflow/Unicode tests | Case folding preserves UTF-16 positions, at most 12 terms/50 sessions/500 in-session locations, helper exclusion and bounded text projection. |
| Usage | Actual helper/provider log fixtures | Local token and per-call context comparisons are estimates; sends, provider receipts and provider limits remain separate. Cumulative reset handling and Claude message deduplication retain source semantics. |

Golden data is generated by executing pinned upstream functions with synthetic public inputs.
For history captures, only configuration and diagnostic sinks are stubbed. This is different from
signed-in browser observations and is identified in each manifest. Original source remains unmodified.
