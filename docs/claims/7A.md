## Implemented 7A contract

`crates/cos-core/src/browser_protocol.rs` provides:

1. A **strict normalized internal identity frame** pinned to `BRIDGE_PROTOCOL == 14` and to a bounded 8 KiB input. It rejects malformed JSON, future/old versions, unknown normalized fields, invalid or control-character identities, oversized IDs and integer epochs outside JS-safe range.
2. `DocumentIdentity` binds profile, tab, frame, document, navigation epoch, local session ID/epoch and worker incarnation as separate explicit values. URL/title and origin-derived text are **not** source-of-truth session proofs.
3. `IdentityFence::observe_verified` is **trusted-adapter-only**. A verified first attribution wins; a second tab/frame/profile cannot quietly claim the same local session. Same scope can advance only monotonically in navigation/worker incarnation while retaining the proven local session; same-epoch document changes, implicit session rebinding and stale worker/navigation observations are denied without altering active ownership.
4. `require_current` compares the full exact current identity before any future action admission; partial matching by session/tab or accepting a later unverified counter never authorizes a command. The in-memory register is capped at 2,048 active documents and refuses capacity overflow.
5. Rust regressions cover version mismatch, malformed/unknown/oversized input, first-proof/idempotence, cross-profile/tab/frame races, document/worker staleness, rebind attempts, authority preservation on rejected observations and invalid JS fields.

**Critical boundary:** normalized identity frames are **not the actual upstream browser-extension JSON wire format**. Mapping, authentication/origin/nonce proof, browser transport, explicit disconnect/rebind, command claim/receipt/ACK, crash-safe persistence, CDP integration, MV3 lifecycle and user input remain distinct future tasks (`7B`, `7C`, `7L1`, `7D`). No browser startup or native compatibility is claimed by this Cloud task. Rust `observe_verified` must never be called directly with untrusted extension messages.
